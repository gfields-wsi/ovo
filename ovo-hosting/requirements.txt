# OvO hosting, parts list.
# Python standard library only, plus one extra part.
# psycopg is the Postgres driver for Python, with its
# prebuilt binary. It is used only when DATABASE_URL is set,
# on Render. Local work and local tests use SQLite and need
# no extra part.
# The two lines below are the same as psycopg[binary]. They
# are written out in full because the bracket form fails to
# resolve on this index: it asks for psycopg-binary 3.2.0.dev1,
# a version that does not exist.
# Version 3.2.10, not 3.2.0: Render defaults to Python 3.14,
# and psycopg-binary 3.2.0 has no Python 3.14 wheel, so pip
# on Render cannot find it. 3.2.10 is the lowest version with
# a Python 3.14 wheel, and it also works on Python 3.12.
# Python is also pinned to 3.12.13 in render.yaml, to match
# the version tested here, so the build does not drift to
# a new Python default.
psycopg==3.2.10
psycopg-binary==3.2.10
