# Audit scorecard design contract

Status: card design pending Greg design. No design is invented here.

## Data fields available to the card

From scorecard.json, format ovo-audit-scorecard 1.0, generated on
every audit run from the same live data as gaps.json:

- store_url
- product_count
- core_pass, core_total, core_score_pct, core_score
- full_pass, full_total, full_score_pct, full_score
- post_ovo_core_pass_projected, post_ovo_core_score
- post_ovo_full_pass_projected, post_ovo_full_score_projected
- gap_count_total, gap_count_per_product_fields, gap_count_store_level
- gap_counts_by_field, gap_counts_by_type
- untrusted_flags_count
- agentic_commerce_ready_native, agentic_commerce_ready_projected
- per_product: product_id, product_name, sku, core_pass, core_total,
  core_score_pct, post_ovo_core_pass_projected,
  post_ovo_core_score_pct_projected, gap_count, field_gap_count

## Json payload

File: scorecard.json, in the same folder as gaps.json.
Format: ovo-audit-scorecard 1.0.
The payload is generated by audit.py, not typed by hand.
