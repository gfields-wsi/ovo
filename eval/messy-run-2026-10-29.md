## Method correction — read this before using the numbers

Two runs were made, and only the second counts.

1. First run (DISCARDED): the harness used the Store API list
   endpoint. That endpoint served a stale clean copy of the
   catalog at run time, so the agent's answers cited facts that
   had been stripped from the live products. Those answers were
   a cache artifact, not a messy measurement, and are not counted
   here.
2. Second run (THIS FILE): the catalog was built from the
   individual product endpoints, one per product, with full
   fields (id, sku, price, currency, is_in_stock,
   is_purchasable, low_stock_remaining, rating, review_count,
   sizes, colour, category, short description, description,
   image, image_alt, weight, dimensions). That snapshot is the
   basis for every score below.
